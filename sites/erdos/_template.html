Model markers show selected public or API releases, using each provider’s announcement dates. Select a marker for its source and the first available snapshot on or after release. They provide context, not attribution of solutions to a model.

“Open / unresolved” groups all seven non-resolved statuses, including independence from ZFC. Ambiguous statements and literature reviews are overlapping attributes. A dash in the table means this snapshot does not break out Lean formalization for that status.
