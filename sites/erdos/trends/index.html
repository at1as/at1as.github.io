A window that extends beyond the saved history is marked incomplete; no rate or multiplier is shown. Windows for different releases overlap. Changes observed after a gap may have occurred earlier.

How to read these charts. We match problem numbers between the same saved snapshots used in the Sankey. New and removed entries are counted separately. Duplicate IDs are excluded from matching, and any residual is shown as “unmatched rows.” Monthly components reconcile exactly to the total change.

Dates are when a saved snapshot first records a change, not verified mathematical discovery dates. Gaps include days without updates and revisions rejected for invalid status data. Changes that appear and disappear between snapshots are not recoverable. The status data does not consistently identify which model, if any, helped solve a problem.
