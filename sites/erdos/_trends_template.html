How the numbers are counted

We compare problem numbers across the same saved snapshots as the Sankey. A change is counted each time it appears, so a problem can be counted more than once if its status changes back and forth. Problems added to or removed from the database are counted separately.

Rates count changes to existing problems. The average starts from the last snapshot on or before the chosen period and uses the actual number of days between snapshots. Monthly bars assign each change to the month it first appears. The first and last months cover only the available dates.

Gaps include days without updates and revisions skipped because of invalid status data. Changes between snapshots may be missed or recorded later. Duplicate problem numbers cannot be matched reliably; their effect on the total is shown as “unmatched changes.” All monthly counts add up to the net change.
