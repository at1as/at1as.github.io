# Fusion Atlas — The paths to fusion power

A buildless editorial explainer at `/sites/fusion/`. Source lives in this repository. No API, CDN, database, external fonts, live news, or client framework. The first release is a reviewable local build; publication remains separate.

## Preview

From the repository root:

```sh
python3 -m http.server 4180 --bind 127.0.0.1
# http://127.0.0.1:4180/sites/fusion/
```

The full Jekyll host also works with `make serve` at http://localhost:4000/sites/fusion/.

If a Jekyll watcher is running, run production checks in an isolated destination so its development rebuild does not overwrite the production sitemap:

```sh
JEKYLL_ENV=production bundle exec ruby -E UTF-8 -S jekyll build --destination /tmp/fusion-atlas-production
python3 scripts/check-seo.py --site-dir /tmp/fusion-atlas-production
```

## Data and checks

`_handoff/` retains the supplied ZIP contents, including canonical JSON, build spec, dictionary, original validator and manifest. It is excluded from Jekyll output by its leading underscore. `fusion_atlas.json` is the byte-identical public canonical download. `data.json` is generated by `_extract.py`; it joins canonical claims, sites, sources and assessments for rendering, preserving native fields and intentional unknowns. `_copy.json` contains reviewed display wording alongside the exact source wording it replaces; the adapter fails if an upstream record changes without a fresh copy review. The canonical download remains unmodified. Narrative fuel descriptions come from the accompanying report. Never edit the presentation data independently.

```sh
python3 sites/fusion/_extract.py
python3 sites/fusion/_validate.py
node sites/fusion/_test.mjs
node sites/fusion/_reactor-test.mjs
node sites/fusion/_assets.mjs
rsvg-convert sites/fusion/share-card.svg -o sites/fusion/share-card.png
JEKYLL_ENV=production bundle exec ruby -E UTF-8 -S jekyll build
make check-seo
```

The validator checks manifest integrity, canonical relationships and scientific/financial distinctions. Model tests exercise the supplied worked examples, per-shot Inertia accounting, negative output, zero capture/thermal efficiency, invalid driver efficiency, undefined ratios, URL bounds, target costs and all diagram states.

## Editorial boundaries

Snapshot: **22 October 2026, America/Los_Angeles**. The dataset preserves the supplied research snapshot. The publication review checked central physics claims, selected company evidence and architecture descriptions against primary sources; it did not reproduce experiments or turn the snapshot into a live feed. Observations, models, precursor results, organizational events and targets retain labels. Date precision and roles survive all evidence views. Currency, funding type, approximations, conditions and revisions survive the financing table; no sector aggregate is computed.

All diagrams and 3D models are original educational concepts, not device CAD or reconstructions, and are not to scale. Part positions and mechanical details are illustrative. Small targets are enlarged for inspection. SVGs are conceptual, not to scale. Timing is presentational. Company architectures with special constraints retain their profile explanation: planar-coil stellarators, Xcimer hybrid drive, First Light FLARE, laser fast ignition, and Fuse's test device versus proposed energy concept.

## 3D implementation

`reactor-explorer.js` is loaded on demand when a model enters the viewport. `reactor-geometry.js` provides disposable models, and `reactor-content.js` joins conceptual systems to the reviewed architecture/source records. No motion starts automatically. Rendering is event driven unless energy-path animation is explicitly enabled; animation pauses offscreen and in hidden tabs. Replaced models and closed dialogs release their WebGL resources. Keyboard orbit/zoom and ordinary component buttons provide alternatives to dragging. Browsers without WebGL retain a static schematic and component explanations.
