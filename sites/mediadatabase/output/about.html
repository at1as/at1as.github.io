Media Database

Hosted sample catalog from the open-source Media Database project

This hosted demo showcases a curated sample catalog generated by the open-source Media Database project. When run locally against your own drives, Media Database scans your folders, fetches IMDb metadata, and builds a private searchable website for your collection. Webpages are statically generated and uploaded to the _output/ directory. Rerun the script every time a new file is added to the directory.
